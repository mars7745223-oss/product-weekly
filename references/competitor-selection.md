# 竞品选择、评分与篇幅

区分竞争关系、研究重要性与本期刊入价值。候选名单和评分服务于情报研究，不代替产品决策；内容止于事实与推断。

## 1. 研究任务与关键情报问题

沿用既有研究范围和观察池。初次建立时记录：

- 本品参照、目标人群、主要任务与场景。
- 地区、价格带、产品形态、出刊区间及研究时间跨度。
- 三至五个关键情报问题（KIQ），以及读者需要理解的外部变化。

KIQ围绕已交付能力、具体任务体验、商业生态、竞争关系或技术迁移。例如“哪些产品已改变同一任务的使用方式”，不用“我们应该开发什么”。
用户未提供内部战略、客户或资源时，以给定范围及公开定位为依据，暂定假设写入补充文本，不假设本品痛点、客户流失或未来路线图。
比较对象以具体产品线和适用地区为单位；同一品牌可有不同关系与研究层级。知名度、融资额和媒体热度不能单独决定入选。

## 2. 五维竞争边界

逐维记录关系、支持证据、适用范围及未知项，不用单一相似度分数替代：

| 维度 | 判断依据 |
|---|---|
| 用户重叠 | 是否服务相同或相近的人群；公开定位与使用自述分别记录 |
| 需求重叠 | 是否解决同一核心任务，而非仅共享产品类别 |
| 场景重叠 | 是否在相同情境中被使用或选择 |
| 预算竞争 | 是否有同一次购买比较、采购或替代选择的具体证据 |
| 能力重叠 | 哪些已交付能力可互相替代；相似架构不等于相同任务 |

预算关系没有公开证据时保持未知，不能仅凭价格接近、都属消费电子或共用总预算认定竞争。
五维边界描述“在哪里竞争”；六维CPS描述“研究优先程度”，两者独立保存，不把五维求和当CPS。

## 3. 六类多标签

| 标签 | 使用条件 |
|---|---|
| 直接竞争 direct | 人群、核心任务及购买选择明显重合 |
| 间接竞争 indirect | 需求相近，形态、方式或主要场景不同 |
| 替代 substitute | 通过不同方式完成同一任务，存在替代依据 |
| 潜在进入 potential_entrant | 当前未直接竞争，但有具体进入信号及相关资源 |
| 标杆 benchmark | 某项机制、体验、商业或技术能力具有明确研究价值 |
| 新兴颠覆 emerging_disruptor | 有结构性改变竞争规则的具体潜力；记录候选性质和依据 |

标签可多选，附依据和时间；“新兴颠覆”标签不是颠覆已经成立。标签、研究Tier、标杆属性和正文栏目分别判断。

## 4. 候选发现与资格筛选

从实际用户替代选择、公开产品与行业资料、论文/开源、商业生态、市场扩展及资本/组织线索发现候选。融资和招聘只能提供线索，不能单独证明增长或产品能力。
按[覆盖计划](coverage-and-priority.md)给适用入口与外围探索分配预算，不仅从最容易读取的平台发现候选。中文消费端、非开发者和不同地区入口的失败须记录；不将英文工具社区代表全部目标用户。外围探索可按时间或单元数配置，不强制百分比，也不以凑候选数替代研究。
CRM、输单、采购和赢单指标仅在用户提供数据时使用；社区提及次数不等于销售遇到率，评论不能推算客户流失。
先判断是否符合范围、解释至少一个KIQ，并有竞争关系或相关机制的基本证据，再进入评分。
资格结果记录为正式评估、待证观察、排除/归档；保存理由。证据少但潜在影响大的对象留观察池，不因未知而打低分排除。
默认采集至少三个竞品产品线、其中至少两个核心对标。这是检索覆盖目标，不是正文配额；信号不足时缩减内容，把范围与缺口写入补充文本。
达到对象数量不证明覆盖充分；完整性只相对于明确的研究范围和检查计划描述，不能保证开放网络无遗漏。
附件或案例中的候选数量仅作资源参考，不强制建立30—50个对象或每期重新铺开全市场。
XREAL候选种子可从VITURE、RayNeo（雷鸟）、Rokid起步，按产品线与地区再分层；不代表固定型号或已核验状态。入口见[来源种子](source-seeds.md)。

## 5. 六维CPS

CPS为可选工具；关系与分层已有清楚依据时，不为完成字段强制打分。启用时采用以下默认模型；按研究目标调整须记录权重版本和原因，权重合计1，同一轮对象使用相同范围、周期和模型：

| 键 | 维度 | 权重 |
|---|---|---|
| customer_overlap | 客户与场景重叠 | 0.25 |
| competitive_threat | 竞争威胁 | 0.25 |
| growth_momentum | 发展势头 | 0.15 |
| capability_advantage | 关键能力优势 | 0.15 |
| scope_relevance | 范围/KIQ相关性 | 0.10 |
| learning_value | 研究借鉴价值 | 0.10 |

评分锚点如下；2、4分必须给出介于相邻锚点的具体依据。1分须有支持低水平的证据，不能代表“没有找到资料”。

| 维度 | 1分 | 3分 | 5分 |
|---|---|---|---|
| 重叠 | 核心人群、任务明显不同 | 部分人群或任务重合 | 核心人群、任务高度重合，有具体替代选择证据 |
| 威胁 | 有证据显示影响仅限非核心范围 | 部分核心任务形成替代或价格压力 | 多项已交付变化扩大核心替代性或生态控制，影响路径有充分支持 |
| 势头 | 同期证据显示停滞或收缩 | 持续交付或兑现单项扩展 | 同期多项量化增长或扩展已兑现 |
| 优势 | 明确对照下相关能力较弱 | 大致相当，存在局部差异 | 关键能力有明确领先及产品意义的验证 |
| 相关性 | 仅涉及边缘研究问题 | 能解释一个当前KIQ | 直接关联核心KIQ、研究期限或关键生态位置 |
| 借鉴 | 已知机制重复，新增解释有限 | 有清楚机制和比较价值 | 实现、数据或应用证据充分，支持深入机制与迁移分析 |

scope_relevance替代对未知内部战略的揣测。优势评分声明公开比较对象；缺乏对照保持未知。势头区分交付、地域拓展与商业增长，融资不等于用户/收入增长。
同一证据可以关联多个维度，但须解释各自影响，避免把一条发布重复奖励为重叠、威胁、优势和势头。

## 6. 未知、覆盖率与辅助分

每维保存得分及依据；未知用null，不补1、3或想象数值，不以置信度乘分折减CPS。
令K为有依据的已知维度，c = Σ(K中的权重)，a = Σ(K中的权重×得分)：

- coverage = c，表示有依据评分维度的加权覆盖，不是证据充分度、市场覆盖率或正确概率；引用存在还须核查其支持范围。
- 有已知维度时，bounds = [20×(a + 1−c), 20×(a + 5×(1−c))]，按未知维度可能取1—5计算；全部未知时bounds=null，不展示无信息的20—100范围。
- 只有六维均已知时给CPS点分：cps = 20×a；否则cps=null，报告覆盖率及范围。
- 不对已知维度重新归一化，不能把低覆盖对象制造成完整高分；重叠或威胁未知时，Tier保持暂定。
- Threat Score = 20×competitive_threat，Learning Score = 20×learning_value；对应维度未知则辅助分也为null，不另造加权模型。

CPS实际范围20—100，是内部序数加权工具，不是行业标准、威胁概率或市场份额。1—5分锚点不证明等距，权重是研究目标下的判断；bounds只是未知维度取值范围，不是统计置信区间，也未覆盖全部证据错误。区间交叠时不强行宣布排序确定。

真正依据CPS总分或范围安排关注顺序时，必须保存至少一组合理权重变化、变化理由和排序/Tier结果，总和仍为1；区分权重影响与新事实造成的调整。若名单随之改变，记录不稳定及依据，不用小数点制造精确感。只展示维度、不依CPS排序时不强制敏感性计算。操作示例见[覆盖与优先级](coverage-and-priority.md)。

## 7. Tier与研究组合

- Tier 1：当前核心关系明确、重要性与证据充分，逐期重点检索，持续维护档案。
- Tier 2：部分竞争或发展较快，轮换深入采集，重要事件触发复评。
- Tier 3：外围、潜在进入或证据不足，低频扫描与事件核验。
- Benchmark Pool：独立标杆研究属性，可与任一Tier重叠；低威胁、高研究价值不应因CPS较低被自动排除。

Tier综合考虑关系、CPS范围、Threat/Learning、近期变化和研究资源，保存选择理由；不机械套分数阈值升级，也不只取综合分最高的对象。
沿用稳定竞品ID；初筛与定稿的资格/Tier不同，记录各自时间、阶段、证据与改变原因，最终状态明确指向定稿记录。资料可读性和本周是否有消息只影响当期采集/刊入，不能单独证明长期竞争关系改变。
研究层级与刊入层级独立：高Tier潜在进入者不自动写进核心对标；本期无重要变化的核心对象也不必凑内容。具体档案和分析内容见[竞品研究](competitor-research.md)。

## 8. 正文安排与边界

本周必读之后先列本品，再列核心对标、常规/细分及商业生态；技术前沿一到两个独立专题。核心对标按高度任务/购买重合判断，常规/细分按部分任务、价格或特定能力判断，不等同于Tier名称。
本品默认一个简短部分，专属部分最多三个，相关内容约不超过正文30%；竞品直接相关内容至少一半，不能被本品细节或技术泛论挤走。按实际内容计入比例，不靠标题规避。
竞品评论融入对应产品，不单列原声栏目。保留正负体验及不同解释；采样和完整原文入补充文本，不堆放孤立摘录。
正文直接呈现变化、对比和解释，保留来源及决定含义的时间、地区、交付条件；不展示类型标签、方法、置信度、评分或ID，不输出功能建议、机会清单、验证动作、负责人或排期。

## 9. 行业特别观察门槛

默认无相邻替代品或潜在进入者栏目。只有证据同时支持以下变化，才在本品之后增加特别观察：

1. 新能力或成本结构足以改变多个产品的核心任务、购买选择或产业分工，而非单项参数领先。
2. 已有可核验交付、公开可复现测量或具体系统演示，能说明关键能力及条件。
3. 有可信规模应用路径，关键硬件、功耗、成本、内容或供给条件已有证据，未被未知条件完全支配。

融资、传闻、概念视频、孤立论文指标或“颠覆行业”宣传不够。关键条件不明时只入补充线索；适合研究的机制可进技术专题，但不能写成行业颠覆已成立。

## 10. 重评与记录

每期核验近期变化，月度轻量重评核心池，季度复核边界与外围池；这是研究节奏，不自动创建监测或提醒。
直接替代品交付、进入同一市场、重大能力/渠道变化、重要反证或用户修改范围触发提前重评。融资、招聘可触发查证，不能单独升Tier。
访问失败和连续几期无消息不能直接降级；先区分读取缺口、事件稀少与竞争关系改变。保留旧判断、修改日期、新证据和改变原因。
观察池、评估及修订字段见[证据记录](evidence-model.md)。沿用既有ID，不新增假评分；记录范围/KIQ、五维关系、标签、资格、模型、证据、覆盖率、CPS范围、辅助分、Tier及复评依据，均放补充或台账。
